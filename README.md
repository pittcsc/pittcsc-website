# Pitt CSC Website

The Pitt CSC website, built with Gatsby, Tailwind, and Framer Motion.

## Run locally

With a compatible Node/npm runtime, run:

```sh
npm ci --legacy-peer-deps
npm run develop
```

Open http://localhost:8000.

See [CONTRIBUTING.md](CONTRIBUTING.md) for setup and contribution workflow,
[development instructions](docs/DEVELOPMENT.md) for runtime, integration, and testing
details, and the [repository guide](docs/REPOSITORY.md) for architecture and content sources.
